## v3 新增：經文詳細 sticky-menu + 三層連動下拉

- **sticky 經文導覽列**（`bible_v3_sticky_dropdown.html`）：整合於頂欄內、捲動時整列固定於視窗頂部，永不滾出畫面。
- **三層連動下拉**：`六藏分類 → 書卷 → 章節`
  - 第一層六藏分類（全部＋六大分類，各標卷數）
  - 第二層書卷（依所選分類列卷，各標章數；選「全部」時依 10 細類分組）
  - 第三層章節（章節數字格，選取即跳轉線上閱讀）
- **目前位置 chip**：即時顯示「書卷 · 第 N 章」，並同步三顆下拉標籤。
- **閱讀器章節目錄下拉**（內文 menu 強化）：工具列新增「章節目錄」按鈕，展開本章卷全部章節，目前章高亮。
- **空白／斷連加固**：`html{scroll-padding-top}` 防止 sticky 頂欄遮蓋錨點；下拉不溢出視口；經文導覽列採卡片底避免透明空白。
- **大幅空白修復（v3）**：補上 `<div class="app">` flex 包覆層（CSS 本有 `.app{display:flex}` 但 HTML 缺少該層），使側欄與主區在寬螢幕上**並排**而非上下堆疊，消除頂欄上方一整屏空白。※ 注意：`bible_v2_整合互動版.html` 與 `bible.html` 亦缺少此包覆層，寬螢幕下同有此空白問題，如需一併修復請告知。
- **多裝置完整模板與易用性（v3 最終調整）**：
  - **hover 展開**（僅滑鼠裝置）：滑鼠移至「六藏分類／書卷／章節」或閱讀器「章節目錄」即展開、移出即收合；觸控／鍵盤仍以點擊切換（`matchMedia("(hover: hover)")` 判定）。
  - **手機版**：舊頂欄快速跳轉隱藏，改由經文導覽列提供三層下拉（已實測無溢出）；下拉與章節目錄採 `min(92vw/88vw, …)` 限寬、觸控目標 `min-height:38px`。
  - **首頁入口**：`index.html`＝v3 副本，資料夾直接開啟即進入完整版。
- **閱讀友善度與連結完整性（v3）**：
  - **功能文章內頁**：新增「上一篇／下一篇」導覽（含已是最前／最後一篇之禁用態），搭配既有「返回文章列表」。
  - **閱讀器空章節**：若某章暫無經文，顯示友善提示與「返回書卷導覽」按鈕，不再空白。
  - **首／末章**：「前一章／後一章」改為禁用態按鈕（附 title），取代原先空白佔位。
  - 閱讀版面：17px／行高 1.95／Noto Serif、多欄、行動版單欄，確保易讀。

## Favicon 與 PWA／完整網站功能（v3 補齊）

- **Favicon**：`favicon.svg`（向量）、`favicon-32.png`、`favicon.ico`、`apple-touch-icon.png`（Apple 主畫面），navy 圓角＋金色十字與打開的聖經書卷；`head` 已掛 `<link rel="icon">` 多版本。可重新生成：`python make_icons.py`。
- **PWA（可安裝、離線）**：`manifest.json`（名稱／theme_color `#1f2a44`／背景 `#f6f1e6`／192+512 圖示）＋ `sw.js`（快取 app shell，含 `assets/bible_text.js`，同源離線退回首頁）。註冊僅在 `https`／`localhost` 生效（GitHub Pages 即可用）；本機 `file://` 不會註冊。
- **SEO／社群**：`keywords`、`author`、`theme-color`、Open Graph（og:title/description/image/type/locale）與 Twitter Card meta。
- **動態頁面標題**：隨章節／文章／檢視自動更新 `document.title`（如「創世記 第1章｜聖經Bible」）。
- **閱讀進度條**：頂端金色漸層細條，隨捲動顯示閱讀進度。
- **分享**：章節與文章支援 Web Share API（行動裝置原生分享），不支援時退回複製文字。
- **列印**：章節與文章皆可列印，`@media print` 僅輸出內容區、隱藏側欄／頂欄／浮動導覽。
- **字級記憶**：閱讀器字級（`changeFont`）寫入 `localStorage("bible_font")`，重訪仍沿用。

> 註：`og:image` 現為相對路徑 `favicon-512.png`；若上線 GitHub Pages 建議改為絕對網址以利社群抓取。
